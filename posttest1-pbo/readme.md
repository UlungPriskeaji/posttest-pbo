Posttest 1 PBO
Sistem Penjualan Dan Inventaris TCG

Deskripsi Program: 
Program ini merupakan program sederhana dengan tema Sistem Penjualan dan Inventaris TCG dan digunakan untuk mengelola data toko, kartu TCG, pelanggan, dan transaksi.

Penjelasan Program:
Program terdiri dari 4 class utama, yaitu:
1. Class toko: digunakan ntuk menyimpan nama, alamat, dan status toko. Pada class ini terdapat instance method untuk menampilkan informasi toko, class method untuk mengubah status toko, dan static method untuk mengecek stok.
2. class KartuTCG: digunakan untuk menyimpan data kartu seperti nama, jenis TCG, harga, dan stok. Stok dibuat sebagai private attribute dan diakses menggunakan property getter dan setter.
3. Class Pelanggan digunakan untuk menyimpan data pelanggan berupa nama dan ID pelanggan.
4. class Transaksi: digunakan untuk menyimpan data transaksi pelanggan, kartu yang dibeli, dan jumlah pembelian. Class ini juga menghitung total harga berdasarkan harga kartu dan jumlah pembelian.

Program menggunakan list untuk mengelompokkan object dan for untuk menampilkannya. Property setter juga digunakan untuk memvalidasi stok dan jumlah pembelian agar tidak menerima nilai yang tidak sesuai.
